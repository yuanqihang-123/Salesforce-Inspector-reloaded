# Export Query History 优化 Spec

状态：Implemented（自动化测试通过，真实 Salesforce 浏览器验收待完成）  
日期：2026-10-14

Export Query 使用可搜索、可预览的历史面板。成功执行的查询自动保存；用户可用方向键查找历史，再按 Enter 直接载入并执行。单条删除立即生效，不提供 Undo。

## 自动保存与容量

- 历史存储于 `insextQueryHistory`，查询完整执行成功后自动新增或更新记录；零条结果也属于成功。失败查询不加入历史。
- 默认保留最近 100 条，100 不是固定上限。可在设置中的 `Number of queries stored in the history` 修改，对应 `numberOfQueriesInHistory`；重新打开 Export Query 页面后使用新容量。
- 同一查询原文和 Tooling API 模式精确去重，再次成功执行后置顶并更新 `lastExecutedAt`（Unix 毫秒时间戳）。超出容量时移除最旧记录。
- 仅预览、载入或新标签页打开不增加历史、不更新执行时间。Enter 触发执行后，只有成功才更新历史。
- 不增加收藏、Org 筛选、结果条数、执行耗时或高级筛选；历史仍为全局历史。

## 页面控件

保留 Templates 和 `History (数量)` 入口。隐藏 Saved Queries 下拉框、Query Label 输入框、Save Query 按钮及其更多菜单（含 Remove Saved Query 和 Clear Saved Queries）。旧 Saved Queries 数据保留，不迁移、不删除；日常复用查询通过自动历史完成。

## 历史面板

### 布局与焦点

- 浮层桌面宽度 960px，不超出视口，两侧至少留 16px；最大高度为视口高度的 70%。
- 顶部显示搜索框、匹配条数、More 菜单和关闭按钮。下方左侧历史候选列表占 55%，右侧显示完整查询预览；两侧各自滚动，预览操作区保持可见。窄屏改为上下布局。
- 打开时清空搜索条件，聚焦搜索框，默认选中最新历史。点击列表行或上下键只改变选中项和预览，不修改编辑器、不执行查询。
- 点击面板外部、再次点击 History 或 Escape 关闭后，焦点返回 History；成功载入后关闭面板并聚焦编辑器。

### 搜索与排序

搜索本地完整查询原文，忽略大小写，去掉首尾空白，按空白分词且要求全部词匹配。不发起 Salesforce 请求，不改变最近成功执行优先的排序。显示 `匹配数 / 总数 queries`。

搜索变化后，选中项仍匹配则保留，否则选中首条；无匹配清空预览。空历史显示 `No query history yet`，无匹配显示 `No matching queries` 并提供 Clear search。

### 候选项固定三行

每个候选框仅展示以下三行，不再在左上角单独显示对象名标题，也不增加时间或 API 标记行：

1. 顶层 SELECT 后、FROM 前的字段表达式，包含函数和完整子查询。
2. 顶层 FROM 后的对象名。
3. 对象名之后的剩余查询，包括别名、WHERE、GROUP BY、HAVING、ORDER BY、LIMIT、OFFSET 等所有内容。没有剩余内容时保留空行。

每行单行展示，过长时以省略号截断；完整查询始终可在右侧查看。展示可压缩空白，但搜索、存储和载入仍使用完整原文。对象识别忽略子查询、字符串和注释内的 FROM；无法可靠拆分或其他查询类型时，首行显示查询摘要，第二行显示 `Query`，第三行留空。

执行时间和 Data API / Tooling API 信息放在候选按钮的悬停提示中；旧记录时间显示 `Time unavailable`。每项右侧提供独立删除按钮，不触发选择或载入。选中项使用背景与左侧边线标识。

### 完整预览

展示完整查询，无 300 字符限制，支持复制和滚动。SOQL 使用语法高亮与格式化；保留字符串和注释内容，失败时回退原文。预览不得修改存储或载入文本。

预览底部保留 `Load query` 和 `Open in new tab`；无选中项或执行中禁用。

## 键盘载入并执行

在搜索框或候选按钮获得焦点时，上下键选择相邻结果并滚动到可见位置。按 Enter 直接：

1. 将选中历史的完整原文和 Tooling API 模式载入当前查询标签页，持久化标签页并刷新自动补全。
2. 关闭历史面板，聚焦编辑器。
3. 触发 Run Export。

Enter 是直接替换并执行的快捷操作，即使当前有未执行的编辑也不弹出替换确认。事件必须阻止默认按钮点击及冒泡，避免重复执行。输入法组合输入中的 Enter 不触发此操作；无匹配项、正在执行、替换确认或 More 菜单打开时不触发此快捷操作。标签页持久化失败时保留面板并显示错误，不开始执行。

## 按钮载入与新标签页

`Load query` 只载入，不自动执行。当前有尚未成功执行的修改时显示 `Replace the current query? Your edits will be overwritten.`，提供 Cancel、Open in new tab、Replace。取消保留内容；Replace 载入当前标签页；Open in new tab 创建内部查询标签页并激活。

修改按各标签页基线判断：初始恢复、新建、载入时建立基线，成功执行时更新；失败执行不更新。文本或模式相对基线改变且查询非空视为有修改。

新标签页打开前保存原标签页实时文本与模式，保留原结果。新标签页填入历史原文、建立基线、结果为空，并持久化；不自动执行。

载入不同查询或模式时清空旧结果和状态；相同查询与模式可保留结果。Tooling 模式强制 `queryAll = false`；当前标签页载入 Data API 查询保留当前 `queryAll`，新标签页默认 false。历史不增加 `queryAll` 字段。

执行期间可搜索、预览和删除历史，但按钮载入与 Enter 执行均不可用，并提示 `Wait for the current export to finish`。

## 删除与清空

- 点击删除立即从持久化历史和列表移除，不弹确认、不提供 Undo，也不保留恢复快照或撤销计时器。删除不影响编辑器、查询标签页、结果或旧 Saved Queries。
- 删除选中项后选择当前过滤结果中下一项，若无则上一项；列表为空时清空预览。删除非选中项保持原选择。
- 被删除的查询只有再次成功执行后才会重新进入历史。
- More 内提供 `Clear all history`，无历史禁用。操作前确认删除全部历史，包含搜索未显示项；取消保持状态，确认清空全部历史与预览，不可撤销。
- 删除前重新读取持久化列表，按完整查询文本和模式定位，不能用过滤列表索引操作存储。写入失败保留记录并显示错误。

## 兼容性与可访问性

旧记录缺少时间仍可搜索、预览、载入和删除，保持原有顺序。忽略损坏条目；面板打开或相关 storage 事件发生时刷新列表。成功查询的历史写入失败时显示错误，查询结果仍可用。

History 提供展开状态和关联面板标识，搜索、预览及删除按钮有可访问名称，选中项提供选中状态。Tab 可访问所有操作，Escape 优先关闭确认框或菜单再关闭面板。错误通过 alert 宣告，键盘焦点清晰可见。

## 验收标准

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| AC01 | 成功、零结果或失败执行 | 成功与零结果自动保存，失败不增加历史 |
| AC02 | 默认容量或设置为 150 | 默认 100；可保留超过 100 条，超限移除最旧记录 |
| AC03 | 再次执行相同查询与模式 | 不重复，置顶并更新时间；不同模式保留独立记录 |
| AC04 | 打开、搜索及方向键选择 | 正确匹配完整原文，选择更新预览，编辑器不变 |
| AC05 | 含子查询、注释、字符串及多个末尾子句 | 三行字段 / 主对象 / 全部剩余子句拆分正确，原文不变 |
| AC06 | 长字段和条件、无 WHERE 查询 | 候选固定三行，长行省略，空第三行保留，完整预览可读 |
| AC07 | 上下键选中后 Enter | 直接载入当前标签页并执行一次，关闭面板，无替换确认 |
| AC08 | 输入法、无匹配或执行中按 Enter | 不执行、不覆盖编辑器 |
| AC09 | 标签页持久化失败后 Enter | 面板保留并报错，不触发执行 |
| AC10 | 点击 Load query 且当前有编辑 | 保留确认流程；仅载入，不执行 |
| AC11 | Open in new tab | 原编辑与结果保留，新标签页激活且结果为空，不执行 |
| AC12 | 删除选中或非选中历史，再关闭或刷新 | 仅目标被移除，选择正确，无 Undo 或恢复入口 |
| AC13 | 过滤状态下 Clear all history | 先确认，确认后包括隐藏项的全部历史清空 |
| AC14 | 存储失败或旧数据 | 旧记录可用；失败不误报成功或移除记录 |
| AC15 | Export Query 控件区 | Saved Queries、Query Label、Save Query 和相关菜单不可见；旧数据保留 |
| AC16 | Chrome、Firefox、窄视口与键盘 | 无浮层溢出或操作遮挡，三行可读、焦点可见 |

## 实施与验证

实现位于 `addon/query-history.js`、`addon/query-history-panel.js`、`addon/data-export.js` 和 `addon/data-export.css`。沿用 React 与现有查询标签页机制。

`scripts/query-history-test.js` 覆盖完整搜索、容量可配置、精确去重、三行拆分、直接删除、存储失败、标签页保护、方向键与 Enter 单次执行、输入法与执行中限制。真实 Salesforce 请求及 Chrome/Firefox 布局需浏览器人工验收。

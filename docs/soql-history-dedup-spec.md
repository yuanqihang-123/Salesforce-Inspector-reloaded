# SOQL 历史语义去重 Spec

状态：Implemented；自动化验证通过，真实 Salesforce 浏览器验收待完成。  
日期：2026-10-14

## 目标

成功运行的 SOQL 按查询结构识别同一查询。字段、主对象与过滤条件相同，仅字段排列、同级条件排列或字符串外空白不同的查询，只保存一条历史。再次成功运行时，以最后一次执行的完整原文和时间替换旧记录，并置顶。

例如依次成功运行：

```sql
SELECT Id,Name from User where IsActive = true and RP_StatusEventType__c = 'Manual Creation'
```

```sql
SELECT Name, Id from User where RP_StatusEventType__c = 'Manual Creation'  and IsActive = true
```

最终只有一条历史，其 `query` 是第二条原文，包含第二条的字段顺序、条件顺序和空格。

## 查询身份规则

身份由查询结构和 `useToolingApi` 模式组成。结构规范化仅用于比较，不改写编辑器、发送的查询或存储的原文，也不新增存储字段。

| 部分 | 比较规则 |
| --- | --- |
| SELECT | 将同层字段/表达式按无关顺序比较；保留函数名、参数顺序及别名 |
| FROM | 比较对象与对象别名；对象不同视为不同查询 |
| WHERE | 将条件解析为布尔结构；同级 AND 或 OR 的条件顺序不影响身份；同运算符嵌套分组合并 |
| 分组与 NOT | 去掉冗余外层括号；保留 AND/OR 的分组关系与 NOT 作用范围 |
| 子查询 | 递归比较 SELECT、FROM、WHERE，包括关系子查询及半连接子查询 |
| 空白、大小写与注释 | 忽略字符串之外的空白和注释；关键字、对象和字段名忽略大小写；保留 token 边界 |
| 字符串 | 按原文比较，保留大小写、内部空白、逗号及转义；例如 `'Manual Creation'` 与 `'Manual  Creation'` 不合并 |
| 其他子句 | 保留原有 token 顺序及值，仅规范化字符串外空白、大小写和注释；ORDER BY 字段顺序、方向、NULLS 设置、GROUP BY、HAVING、LIMIT、OFFSET、WITH、FOR、ALL ROWS 等差异保留 |
| 模式 | Data API 与 Tooling API 保留独立记录；沿用历史数据结构，不增加 `queryAll` 字段 |

仅做上述可确定的结构等价判断，不执行查询结果对比或完整逻辑证明。数值不同写法、IN 列表值重排、比较运算左右交换、德摩根变换、布尔分配律、HAVING 条件重排等暂不归并。TYPEOF、绑定变量、其他查询类型、无法识别的 token 或不完整结构回退为完整原文精确比较。

## 保存、读取与删除

1. 沿用完整查询成功后调用 `QueryHistory.add` 的时机；零结果也保存。失败执行不新增历史，也不替换此前成功版本。
2. 保存前重新读取持久化历史，移除相同身份的旧条目，加入本次原文、模式与 `lastExecutedAt`，置顶后按配置容量裁剪。
3. 历史只存查询原文、模式与执行时间，不存查询结果集。当前标签页查询结果沿用现有流程，成功执行后显示本次结果。
4. 读取已有 `insextQueryHistory` 时合并等价重复项，按原有最近执行优先顺序保留第一条；缺少时间的旧数据仍可使用。读取本身不写存储，下次成功保存或其他历史写入时持久化合并后的列表。
5. 历史面板选择、删除使用同一身份规则；按旧版写法定位也可以删除对应等价记录，不影响其他 API 模式记录。
6. 写入失败保持原有错误处理，不发布本次未成功持久化的版本；查询结果仍可查看。
7. 旧的手动 Saved Queries 保留精确文本去重，不改动标签、内容或排序；REST 请求历史使用独立逻辑。

## 验收标准

| 场景 | 预期 |
| --- | --- |
| 示例两条查询分别成功执行 | 只保留一条，原文为第二条，时间更新并置顶 |
| SELECT 字段/函数表达式重排 | 同字段、函数、参数与别名时合并 |
| AND/OR 同级重排或相同运算符嵌套 | 合并；混用 AND/OR 时保留布尔分组差异 |
| 子查询字段与条件重排 | 可合并；子查询对象/过滤值/排序变化不合并 |
| 字符串外增加空白或注释 | 合并；字符串内部变化不合并 |
| 更改字段、对象、过滤字段、值或运算符 | 保留不同记录 |
| 更改 ORDER BY、LIMIT、OFFSET 或 API 模式 | 保留不同记录 |
| 等价查询随后失败 | 保留此前成功原文与时间 |
| 旧数据含等价重复项 | 读取保留最新位置条目，下次写入持久化去重 |
| 删除历史或重新打开页面 | 身份定位正确，最新原文可重新载入 |
| 未支持或不完整语法 | 回退精确文本比较，避免错误合并 |
